01 / THE BASICS

Zero ceremony. Just run it in your shell.

No browser, no Electron app, no Python virtual environments. omatts is a single standalone CLI binary that reads text from arguments or stdin and speaks immediately.

What you want to do Terminal Command Notes
Speak text out loud omatts Hello world Quotes optional; multiple words joined automatically
In-text pauses omatts "Hello. [[pause 1]] Goodbye." Inserts N seconds of silence between sentences (0–10s, default 0.5s)
Dynamic in-text volume omatts "Softly. [[volume 2]] And louder." Changes volume for following text (0.1–2, reset with [[volume]])
Pitch-preserving speed omatts --speed 1.4 "Faster speech" Speeds up 0.5–4.0 with pitch unchanged (via ffmpeg atempo)
Output gain / volume omatts --volume 1.5 "Louder audio" Sets master output gain (0.1–2.0, default 1.0)
German language pack omatts -v de/klaus "Hallo Welt" tag/name loads models-<tag> automatically
Symbol normalization omatts "$100 is 50% of €200" Speaks symbols out per pack via models/normalize.txt
Save to MP3 or Opus omatts -o out.mp3 "Save MP3" Writes .mp3 or .opus (requires ffmpeg) alongside .wav
Stream encoded to stdout omatts -o -.opus "Stream" | ffplay - -.mp3 and -.opus stream encoded formats directly to stdout
Hear all voices (demo) omatts voices demo Loads once and cycles through all voices with demo slogans
Clone any voice clip omatts -v ~/clips/speaker.mp3 "Hello" Any 3–10s WAV, MP3, FLAC, or OGG file
Save to WAV file omatts -o speech.wav "Save this" Writes 24kHz float32 WAV to disk without playing
Read from stdin echo "Task completed" | omatts Great for bash pipes, cron jobs, and build alerts
Run OpenAI HTTP server omatts serve --port 8080 Supports speed (0.5–4.0) and response_format (wav, pcm, mp3, opus)
02 / WHY OMATTS IS GREAT

Fast. Voice cloning. Zero dependencies.

Built specifically to do one job brilliantly: turn text into high quality cloned speech directly on your computer without waiting on networks, GPUs, or Python runtimes.

1. Blazingly Fast & Expressive

Runs 9.2× faster than realtime on CPU. Quantized INT8 weights and AVX2/NEON acceleration ensure instant generation on modern CPUs. A background daemon keeps models warm so audio starts within 30ms. Shape delivery with pitch-preserving --speed 0.5–4.0, in-text [[pause N]] silence tags, dynamic [[volume F]], and natural symbol reading via normalize.txt.

9.2× realtime · 30ms latency · in-text tags · normalize.txt

2. Zero-Shot Cloning & Language Packs

Point it at 3 to 10 seconds of any audio file (-v sample.wav) and it speaks in that voice. Includes bundled English and German studio voices (alba, dhh, george, de/klaus, de/juergen). Voice tags like de/klaus switch language packs automatically. Hear your full voice library with omatts voices demo.

-v <clip> · de/ language packs · voices demo · 4ms KV cache

3. Zero Dependencies & Audio Formats

One single C++ file driving ONNX Runtime. No Python interpreter, no PyTorch, no CUDA, no cloud servers, and no API keys. It never sends your audio or text across the internet. Outputs directly to uncompressed 24kHz WAV, compressed .mp3 or .opus, or streams encoded audio to stdout. Drop-in OpenAI /v1/audio/speech server for SillyTavern and Open WebUI.

pure C++ · WAV/MP3/Opus · encoded stdout · 100% local
03 / INSTALLATION

One command. Ready in seconds.

The install script downloads the pre-built Linux x86_64 bundle with pre-quantized models and starter voices. No Python, pip, or PyTorch required.

Requires only curl and zstd. Binary lands in ~/.local/bin, models and voices land in ~/.local/share/omatts.

The installer asks whether to also install the German pack (~120 MB); say yes, or specify up front: curl -fsSL .../install.sh | OMATTS_PACKS=de sh.

Full command manual & build guide ↗
Terminal Automated curl-to-sh install
$ curl -fsSL https://raw.githubusercontent.com/parnoldx/omatts/master/install.sh | sh

  1. Install binary and default models. Run the curl-to-sh command above to install omatts to ~/.local/bin.
  2. Speak your first sentence. Run omatts Hello world in any terminal. The daemon warms up and speaks out loud.
  3. Get daily personal motivation. Run omatts -v dhh "We can fix everything." and conquer your day.
  4. Speak German (optional). Answer y when the installer offers the German pack, then run omatts -v de "Hallo Welt".

Building from source: make build compiles the single C++ file using CMake; make deploy regenerates ONNX weights with export_onnx.py and publishes the release.
