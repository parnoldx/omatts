01 / THE BASICS

Zero ceremony. Just run it in your shell.

No browser, no Electron app, no Python virtual environments. omatts is a single standalone CLI binary that reads text from arguments or stdin and speaks immediately.

What you want to do Terminal Command Notes
Speak text out loud omatts Hello world Quotes optional; multiple words joined automatically
Pick a voice from voices/ omatts -v dhh "Hello world" Voice name from voices/ (e.g. alba, dhh, george, anna)
Clone any voice clip omatts -v ~/clips/speaker.mp3 "Hello" Any 3–10s WAV, MP3, FLAC, or OGG file
Save to audio file omatts -o speech.wav "Save this" Writes 24kHz float32 WAV to disk without playing
Read from stdin echo "Task completed" | omatts Great for bash pipes, cron jobs, and build alerts
Stream to media player omatts -o - "Stream" | ffplay -nodisp -autoexit - Streams raw WAV chunks to stdout
Run OpenAI HTTP server omatts serve --port 8080 OpenAI-compatible drop-in for SillyTavern & Open WebUI
02 / WHY OMATTS IS GREAT

Fast. Voice cloning. Zero dependencies.

Built specifically to do one job brilliantly: turn text into high quality cloned speech directly on your computer without waiting on networks, GPUs, or Python runtimes.

1. Blazingly Fast

Runs 9.2× faster than realtime on CPU. Quantized INT8 weights and AVX2/NEON acceleration ensure instant generation on any modern laptop or desktop. A background daemon keeps models warm so audio starts playing within 30ms of hitting Enter.

9.2× realtime · 30ms to first audio · INT8 CPU

2. Zero-Shot Voice Cloning

Point it at 3 to 10 seconds of any audio file (-v sample.wav) and it speaks in that voice. Includes bundled studio voices (alba, dhh, george, anna). Transformer KV prompt caching restores conditioned voices in just 4ms.

-v <clip> · zero training · 4ms KV cache

3. Zero Dependencies

One single C++ file driving ONNX Runtime. No Python interpreter, no PyTorch, no CUDA, no cloud servers, and no API keys. It never sends your audio or text across the internet. Everything runs 100% locally and privately on your machine.

pure C++ · single binary · 100% local & offline
03 / INSTALLATION

One command. Ready in seconds.

The install script downloads the pre-built Linux x86_64 bundle with pre-quantized models and starter voices. No Python, pip, or PyTorch required.

Requires only curl and zstd. Binary lands in ~/.local/bin, models and voices land in ~/.local/share/omatts.

Full command manual & build guide ↗
Terminal Automated curl-to-sh install
$ curl -fsSL https://raw.githubusercontent.com/parnoldx/omatts/master/install.sh | sh

  1. Install binary and models. Run the curl-to-sh command above to install omatts to ~/.local/bin.
  2. Speak your first sentence. Run omatts Hello world in any terminal. The daemon warms up and speaks out loud.
  3. Get daily personal motivation. Run omatts -v dhh "We can fix everything." and conquer your day.

Building from source: make build compiles the single C++ file using CMake; make dist regenerates ONNX weights with export_onnx.py.
